# To-Do List App

Welcome to my private to-do list app repository! 📝 This JavaFX application helps you manage your tasks efficiently.

## Features

- **Intuitive UI:** A user-friendly interface built with JavaFX for seamless task management.
- **Persistent Storage:** Save and load tasks locally for continuity between sessions.
- **Priority Levels:** Assign priority levels to tasks for better organization.
- **Easy Editing:** Quickly edit, mark as complete, or delete tasks with just a few clicks.

## Technologies Used

- **Java:** Core programming language.
- **JavaFX:** Framework for building rich desktop applications.
- **Scene Builder:** Visual layout tool for JavaFX applications.
- **Git:** Version control for collaborative development.
